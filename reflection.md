# Major Project Reflection

## What advice would you give to yourself if you were to start a project like this again?
-I think that I thought it would be way simpler than the project actually was and then got frazzled when I ran into small errors or bugs, I would focus on getting the basics done before trying to make it look pretty/more complicated. Also I would have been more orgaized from the start and maybe seperated my files earlier.

## Did you complete everything in your needs to have list?
-I did complete everything I put in my needs to have save for some introductory dialogue but I made the sound effects a lot ooler so thats what I spent my time on and I am proud of the sizzling on the grill stopping when you go to other tabs.

## What was the hardest part of the project?
-The logic behind getting everything from each screen and finally checking it too what the customer ordered. The grill screen took me the longest by far because it was what I started with originally and had no clue how I wanted the rest of the game to work with it. I found that splitting it into the systems really helped because the patty/grill doesnt care what the customer ordered, it just cooks the burgers so when something broke I knew exactly where the problem was.

## Were there any problems you could not solve?
-Flow. The game still feels really choppy for me and I wanted to make it flow a lot better but every time I tried to change little things to make it better it all broke collectively so I was really fighting demons with trying to make transitions or introductory video.
